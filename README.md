- **[Shuteye](https://github.com/apexfaucet-hub/shuteye)**: talk to Claude Code with your eyes shut. Your phone listens and reads the answers aloud; Claude Code runs on your own machine. Read-only by default, zero dependencies. Every star plants a tree in [Shuteye Park](https://apexfaucet.xyz/arc/city/#park).
- **[Free USDC on Arc](https://apexfaucet.xyz/arc/)**: paste an address, no wallet connect, nothing to sign.
- **[Agent watchtower](https://apexfaucet.xyz/arc/agents/)**: every agent registered on Arc, checked once an hour: who answers and who can actually be paid.
- **[Arc City](https://apexfaucet.xyz/arc/city/)**: a 3D city where each Arc agent is a tower.
- **[Arc Agent Passport](https://github.com/apexfaucet-hub/arc-agent-passport)**: an ERC-8004 identity on Arc for any AI agent.

Numbers we publish are read from the chain, never estimated.
